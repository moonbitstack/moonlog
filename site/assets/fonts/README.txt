Typefaces used by this site
===========================

All four are self-hosted as WOFF2, latin subset, so a reader in a network that
cannot reach a font CDN still gets the page as designed.

  EB Garamond     display: the wordmark, headings, the italic that answers them
                  SIL Open Font License 1.1 — github.com/octaviopardo/EBGaramond12
  Spectral        text: running prose, captions, table cells
                  SIL Open Font License 1.1 — github.com/productiontype/Spectral
  Courier Prime   the typewriter: labels, navigation, level chips, the stream
                  SIL Open Font License 1.1 — quoteunquoteapps.com/courierprime
  IBM Plex Mono   code: the carbon copies
                  SIL Open Font License 1.1 — github.com/IBM/plex

Subsets were fetched from the Google Fonts API on 2026-10-25 and are served
from this directory; nothing is requested from a third party at run time.
