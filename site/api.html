API reference

Everything the package exports, grouped by what it does rather than alphabetically: a reader looking for a name usually knows which part of the pipeline it belongs to. Times are nanoseconds since the epoch and durations the same; a text that is not a String is a StringView.

Levels

typeLevel{ name : String, value : Int, colour : Colour }

How severe a record is. A value rather than an enumeration, so an application can define its own; only value counts when comparing.

lettrace · debug · info · warn · error · fatalLevel

The six built-in levels, numbered 10 to 60.

fnLevel::parse(name : StringView) -> Level raise Refused

A level by name in any capitalisation, or by number from 0 to 255. warning is warn and critical is fatal.

fnLevel::value(Self) -> Int

Its number. Level::name answers the lower-case name, Level::colour the colour a terminal uses.

fnLevel::label(Self, Profile) -> String

How a profile's logger writes it: WARNING for python, DEBUG-4 and ERROR+4 for slog.

fnLevel::at_least(Self, Level) -> Bool

Whether this level passes a minimum. <, <=, > and >= work too.

fnLevel::named(Self, String) -> Level

The same level under another name, which is how a profile's vocabulary reaches a layout.

fnLevel::syslog · ::logstash · ::otel(Self) -> Int

The three numberings other schemas want: syslog severity, Logstash's 5000 to 40000, and OpenTelemetry's 1 to 21.

typeColourPlain · Red · Green · Yellow · Blue · Magenta · Cyan · White · Grey · Alarm

A terminal colour. Colour::ansi answers the escape, ::name the word, ::parse a word back to a colour (gray is grey).

Values and records

typeValueNull · Bool(Bool) · Int(Int64) · Float(Double) · Str(String) · List(Array[Value]) · Map(Array[(String, Value)]) · Error(String, Array[String]) · Other(String)

A field's value, typed until a layout writes it. Constructors: of_null, of_bool, of_int, of_long, of_float, of_str, of_list, of_map, of_error, of_other.

fnValue::to_text · ::encode · ::write_json(Self) -> String / (Self, StringBuilder) -> Unit

The text form ([a, b], {k=v}, connect: refused) and the JSON form.

typeCaller{ module_path : String?, func : String?, file : String?, line : Int? }

Where in the source a record was made. Every part may be unknown; a layout writes ? for the ones that are.

typeIdentity{ app, env, instance, host : String; pid : Int; start : Int64; offset : (Int64) -> Int }

The process and deployment: what {app}, {host}, {pid} and friends write, and the offset local time is shifted by.

Identity::of(app~, env?, instance?, host?, pid?, start?, offset?) — the parts a deployment knows. Identity::new() names nobody.

typeRecord{ level, target, msg, fields : Array[(String, Value)], tags, caller, thread, spans, time : Int64, seq : Int64 }

One log event, as every sink sees it. fields is ordered; a later field of the same name replaces the earlier one where it stands.

Record::of(level, target, msg) · ::set(key, value) · ::sets(pairs) · ::unset(key) · ::say(msg) · ::at(level) · ::tag(tag) · ::stamped(nanos) · ::numbered(seq) · ::located(file, line~) · ::on(thread) — each answers a copy.

::field(key) → Value? · ::has(key) · ::tagged(tag) · ::copy()

Errors

errorRefused{ at : Int, got : String, want : String }

A value the library will not take: the offset it stopped at, what was there, and what would have been taken. Answered by Level::parse, Filter::parse, Pattern::parse, Schema::parse, Profile::parse, Stream::parse, Colour::parse, Levels::parse, Redact::pattern and Hub::add. to_text() writes it as one line.

Filters

typeFilter

Which records pass, by target, level and optionally message. The syntax is the one RUST_LOG made familiar.

Filter::parse(spec) raise · ::at(level) · ::off() · ::allows(level, target) · ::admits(level, target, msg) · ::lowest() → Level? · ::has_pattern() · ::to_text()

Steps

traitProcessorprocess(Self, Record, Env) -> Record?

One step in a chain. Return the record it was given when nothing changes, a copy when something does, and None to drop it.

typeEnv{ now : Int64 }

The moment a step runs at, in nanoseconds. Env::at(nanos) builds one; the hub passes its own.

typeRedact

Masks fields by name at any depth, at a dotted path, and matches in the message.

Redact::new() · ::key(name) · ::path("req.headers.auth") · ::pattern(regex) raise · ::mask("***")

typeSanitise

Escapes line breaks, tabs and control characters in the message and in string fields, so a message cannot forge a second line.

Sanitise::new()

typeFields

Sets the same fields on every record that passes.

Fields::new() · ::set(key, value)

typeKeep

Conditions on tags, fields and level; every one given must hold. Keep::holds(record) answers whether they do.

Keep::new() · ::tag(tag) · ::field(key, text) · ::level(min)

typeMatch

Keeps a record only when every condition holds. The same three conditions as Keep.

Match::new() · ::tag(tag) · ::field(key, text) · ::level(min)

typeExclude

Drops a record when every condition holds — the inverse of Match.

Exclude::new() · ::tag(tag) · ::field(key, text) · ::level(min)

typeSample

Per level and message, keeps the first first records in each per, then one in every.

Sample::new(first~, every~ = 1, per~)

typeLimit

A token bucket: rate records a second, holding up to burst.

Limit::new(rate~ : Double, burst~ : Double)

typeDedupe

Drops a record with the level, target and message of one kept within the window; the next one kept carries repeated, the number dropped.

Dedupe::new(within~ : Int64)

Layouts

traitLayoutrender(Self, Record, Scene) -> String

Turns a record into one line. Implemented by Pattern, Logfmt, Pretty and JsonLine.

typeScene{ profile : Profile, colour : Bool, identity : Identity }

How a record is shown: whose vocabulary, whether a terminal takes colour, and who is writing.

Scene::new(identity?, profile?, colour?) · ::at(profile) · ::coloured(bool)

typePattern

Literal text with {token} or {token:options} holes; {{ and }} are braces. A preset name stands wherever a pattern does.

Pattern::parse(text) raise · ::source() · ::render(record, scene) via Layout

typeLogfmt

time=… level=warn target=app msg="…" key=value: one line a shell pipeline can cut.

Logfmt::new()

typePretty

A first line with time, level, target and message, then one aligned key = value line per field.

Pretty::new()

typeJsonLine

One object in a schema, with keys renamed, levels written by name or number, and fields at the top or under one key.

JsonLine::new(schema) · ::rename(key, to) · ::levels(Levels) · ::nest(key) · ::encode(record, scene)

typeSchemaSerlog · Pino · Bunyan · Zap · Slog · Structlog · Logstash · Ecs · Gelf · Otel

A JSON shape other tools already read. Schema::name answers the word, ::parse a word back to a schema.

typeLevelsName · Number

How a JSON layout writes a level, when the schema's own choice is not what a pipeline wants.

typeClockLocal · Utc · Rfc3339 · Unix · UnixMs · UnixNs · Custom(String)

How an instant is written. Custom is strftime: %Y %m %d %H %M %S %f %z %:z %% and %.Nf.

Clock::parse(spec) · ::write(out, nanos, offset)

Sinks

traitSinkwrite(Self, Entry) -> Result[Unit, String]

Where entries go. One method; Err is what went wrong, worth telling an alarm about.

typeEntry{ record : Record, line : String }

What a sink is handed: the record, and the line its slot's layout made of it.

typeLines

A sink that writes each line through a function — the seam between this library and wherever you print.

Lines::new(write : (String) -> Unit)

typeMemory

A sink that keeps the newest entries, for a test or a status page.

Memory::new(size~ = 0, everything) · ::records() · ::lines() · ::find(text) → Array[Entry] · ::clear()

typeDiscard

A sink that drops everything, for an application that configures logging off.

Discard::new()

Slots and health

typeSlot

One sink with the settings around it. A value: an application builds it and hands it to a hub.

Slot::new(sink, name~) · ::filter(Filter) · ::at(Level) · ::process(&Processor) · ::layout(&Layout) · ::coloured(Bool) · ::queue(Queue) · ::retries(Int) · ::probe(nanos) · ::on_fail(OnFail) · ::alarm_only() · ::name() · ::status() → Status

typeQueue{ size : Int, batch : Int, wait : Int64, full : Full }

A buffer in front of a sink, drained by the hub when it holds batch records, when wait passes, or at hub.flush().

Queue::new(size~) · ::batch(Int) · ::wait(nanos) · ::full(Full)

typeFullDrop · Block

What a full queue does with a record that arrives: count it as dropped, or write first and make room.

typeOnFailPanic · Ignore · Alarm(&Alarm)

What a slot does when its sink fails.

typeStatus{ name, health, skipped, dropped, suppressed, since, error }

A slot's state, as Hub::status() reports it.

typeFault{ error : String, phase : Phase? }

What went wrong on the way to a sink, and whether an alarm is owed for it.

typeBreaker

Up, down or probing; no I/O and no clock, every method takes the instant.

Breaker::new(probe, now) · ::admit(now) → Bool · ::fault(now, error, remind, tell) → Phase? · ::pass(now) → Phase? · ::resting(now) · ::wait(now) · ::health() · ::skipped() · ::skipped_now() · ::since() · ::failed_since() · ::error()

letprobe_default · batch_default · wait_default5 s · 1000 · 1 s

The policy numbers a slot and a queue start with, named so a caller can read one instead of writing it again.

typeHealthUp · Down · Probing

Whether a sink is writing, skipping, or having its one probing write.

typeTellReport · Silent · Folded

How a failure is told: an incident, silence, or folded into another sink's incident so only the recovery is told.

Alarms

traitAlarmroute(Self, Incident) -> Array[Array[String]] · fallback(Self) -> Fallback · remind(Self) -> Int64

Chooses which sinks an incident is offered to, on which tier, and how long a silence lasts.

typeTiers

The built-in alarm: fixed tiers of names, where * stands for every sink on the log route.

Tiers::from([["loki"], ["mail"]]) · Tiers::new() (standard error alone) · ::with_fallback(Fallback) · ::with_remind(nanos) · ::tiers()

letremind_defaultInt64 — one hour, in nanoseconds

How long an alarm stays quiet about a sink that is still down.

traitDesklogs(Self) -> Array[String] · resting(Self, String) -> Bool · deliver(Self, String, Record) -> Result[Unit, String]

What an alarm walk needs from the sinks around it. A Hub is one; a test is another.

fnsound(alarm : &Alarm, incident : Incident, desk : &Desk) -> Outcome

Delivers an incident through the tiers, adding every failed delivery to it. One success ends the walk; when none does, the alarm's fallback decides whether the program stops.

typeIncident{ sink, kind, phase, error, failures, skipped, dropped, since, at }

A sink's failure, from the first error to its recovery. since is when the failure began, at when this report was made.

Incident::new(sink, kind, phase, error, now) · ::describe(target? = "moonlog") → Record

typeFailure{ sink : String, error : String, at : Int64 }

One failed delivery, on the way to an alarm.

typePhaseOpened · Reminder · Resolved

Which report of an incident this is.

typeFallbackPanic · Ignore

What an alarm does when no tier took the incident.

typeOutcomeHeard · Unheard

How a walk ended.

A target and the fields bound to it. A value, passed in; a library handed none writes nothing.
