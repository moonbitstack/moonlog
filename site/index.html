Every line is
a record.

moonlog keeps a log entry typed until it is written: a level, a target, a message and ordered fields, filtered once, shaped by a layout, and handed to a sink that is allowed to fail.

Pattern

02

The parts

twelve names, each doing one thing, each a value you pass in

01Level

A number, a name and a colour. Six are built in; a seventh is a value you construct.

Level::parse · ::label · ::at_least

02Value

Fields keep their type — null, bool, int, float, string, list, map, error — until a layout writes them.

Value::of_int · ::of_map · ::encode

03Record

One event: level, target, message, ordered fields, tags, caller, thread, instant, sequence number.

Record::of · ::set · ::stamped

04Filter

warn,app=debug,web:*=error. The most specific directive wins; a /regex narrows by message.

Filter::parse · ::allows · ::lowest

05Processor

Eight steps: redact, sanitise, fields, match, exclude, sample, limit, dedupe. A step may drop the record.

Processor::process(record, env)

06Layout

A pattern, logfmt, a pretty block, or one of ten JSON schemas with keys renamed and fields nested.

Pattern · Logfmt · Pretty · JsonLine

07Sink

One method: take an entry, answer Ok or say what went wrong. Nothing else is required.

Sink::write(entry) → Result

08Slot

One sink with its filter, steps, layout, colour, queue, retries, probe and failure policy around it.

Slot::new(sink) · ::at · ::queue

09Breaker

Up, down or probing. It counts what it skipped, remembers what failed and waits before trying again.

Breaker::admit · ::fault · ::pass

10Alarm

Tiers of sinks to try when one fails. * is every sink on the route; one success ends the walk.

Tiers::from([[…], […]])

11Hub

The filter, the global chain, the slot table and the clock. Built by the application, held by nobody else.

Hub::new(clock~) · ::add · ::logger

12Logger

A target and the fields bound to it. Passing one is how a library logs without knowing where it goes.

Logger::info · ::bound · ::enabled
03

No clock, no global

two absences that decide the shape of everything else

Time is a parameter

The hub asks the clock it was given. A record carries the instant it was told, in nanoseconds; the health machine and the steps that sample, limit or dedupe take it as an argument. A test says which instant it means, and the same code runs at a different speed without changing.

Hub::new(clock=fn() { 1_700_000_000_000_000_000L })

Logging is a value

There is no process-wide hub to configure and no default logger to inherit. A module takes a Logger as a parameter and writes through it; handed none, it writes nothing. Two hubs can write the same file in two formats and never meet.

fn handle(log : @moonlog.Logger, req : Request)
main.mbt
let sink = @moonlog.Memory::new()
let hub = @moonlog.Hub::new(
  identity=@moonlog.Identity::of(app="gateway", env="prod"),
  clock=fn() { 1_700_000_000_000_000_000L },
)
let _ = hub.add(
  @moonlog.Slot::new(sink, name="console")
  .layout(@moonlog.Pattern::parse("{time:%H:%M:%S%.3f} {level:<5} {target}: {msg}{fields}")),
)

let log = hub.logger("mirror::sync")
log.info("starting", fields=[("workers", @moonlog.Value::of_int(4))])
// 22:13:20.000 INFO  mirror::sync: starting workers=4
04

Failure is a state

a sink that is down is skipped, not retried in the caller's face

A write that fails moves its slot's breaker. While the breaker says down, records for that slot are counted and dropped until its next probe; a probe is one write deciding. Ten failures in a row back off to five minutes, and a success puts everything back.

What the caller sees

Nothing. The record is written to the sinks that are up, and the one that is down costs a count instead of a failed request.

What a person hears

The first failure opens an incident and an alarm walks its tiers: the other sinks, then the fallback. A reminder follows while it is still down; a resolution follows when it is not.

What a pipeline reads

The incident is a record like any other — level, target, message, fields — so it reaches the same dashboards without a second alerting system.
