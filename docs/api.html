API reference

Everything the package exports, grouped by what it does rather than alphabetically: a reader looking for a name usually knows which part of the pipeline it belongs to. Times are nanoseconds since the epoch and durations the same; a text that is not a String is a StringView. Every value type derives Eq and Debug, so equal, not_equal and to_repr exist wherever a value does; they are not listed one by one. This page is generated from the package's interface.

One hour: how long an alarm stays quiet about a sink that is still down. The interval the alarm cases are written with, so a tier built with the defaults reports a long outage at the same moments they describe.

fnsound(&Alarm, Incident, &Desk) -> Outcome

Delivers incident through alarm's tiers, adding every failed delivery to it. The failing sink is never asked. * stands for every sink on the log route. A sink already tried is not tried again, and a resting one is left out. One success ends the walk; when no tier takes it, nothing more happens here.

Hub and logger

typeHubidentity : Identity, profile : Profile, mut filter : Filter, chain : Array[&Processor], slots : Array[Slot], layout : &Layout, clock : () -> Int64, mut seq : Int64, mut inside : Bool, mut writing : Int32, mut suppressed : Int64

The whole of a running logger: a global filter, a chain of steps every record goes through, a table of slots, and the identity and clock that the application handed in. There is no process-wide hub. An application builds one and passes the Logger values that write to it to the libraries it uses; a library that was handed none writes nothing. Implements Desk.

fnHub::add(Self, Slot) -> String raise Refused

Registers a slot and answers the name it took. A second slot with the same name is refused, and so is the name *, which would make an alarm tier ambiguous.

fnHub::deliver(Self, String, Record) -> Result[Unit, String]

As a Desk: Writes record to the named sink at once, bypassing its queue. Err is what the sink said, or that no sink has that name.

fnHub::dispatch(Self, Record) -> Unit

Sends record everywhere it belongs: through the global chain, then to each slot's own filter and steps, then to its sink. A record made while a sink is already running is dropped and counted: a sink that logs into the hub it belongs to would otherwise never finish.

fnHub::enabled(Self, Level) -> Bool

Whether a record at level could pass, before its target or message is known. Worth asking before building a message that costs something.

fnHub::filter(Self) -> Filter

fnHub::flush(Self) -> Unit

Writes what every queue holds, up to now.

fnHub::identity(Self) -> Identity

The identity records are stamped with.

fnHub::logger(Self, String) -> Logger

A logger writing to this hub under target, which is usually a module path.

fnHub::logs(Self) -> Array[String]

As a Desk: The sinks on the log route, which * stands for.

fnHub::new(identity? : Identity, profile? : Profile, clock? : () -> Int64, filter? : Filter) -> Self

A hub at profile, writing what the filter lets through. clock answers nanoseconds since the epoch. Without one every record carries 0, which is honest — this library never reads a clock — and every test says what instant it means.

typeProfileSerlog · Tracing · EnvLogger · Python · Logback · Slog · Pino
