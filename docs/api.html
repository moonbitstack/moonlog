API reference

Everything the library exports. The root package is grouped by what a name does rather than alphabetically: a reader looking for a name usually knows which part of the pipeline it belongs to. The six subpackages follow, each one a section of its own. Times are nanoseconds since the epoch and durations the same; a text that is not a String is a StringView. Every value type derives Eq and Debug, so equal, not_equal and to_repr exist wherever a value does; they are not listed one by one. This page is generated from the interfaces.

Filters

typeFiltermut base : Level?, rules : Array[Rule], mut pattern : @string.Regex?, mut pattern_text : String

Which records pass, by target, level and optionally message. moonlog/file

A file that rotates itself.

typeFilepath : String, append : Bool, perms : Int32, mkdir : Bool, rotation : Rotation, limits : Limits, compress : Bool, buffer : Int32, clock : () -> Int64, mut handle : Int32?, mut written : Int64, mut opened : Int64, held : @buffer.Buffer

A sink that appends each entry to a file, rotating it when it grows too large or too old. The file is opened on the first write, so a sink that cannot open its file is a failing slot rather than a failure at startup: the health machine puts the sink down, the alarm says why, and a probe retries. reopen picks up a file that an outside tool moved away.
